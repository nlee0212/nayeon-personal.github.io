# BALI OPS · 2026.09.03 – 09.08

이나연 · 발리 4박5일 일정 사이트. **로컬 전용** — 서버도 계정도 필요 없습니다.

**컨셉: 숙소가 목적지.** 누사페니다 스노클링과 강아지 요가는 제외했고, 외출은 선셋 식사와 바투르 지프투어뿐입니다.
유료 데이베드·리조트 스파도 쓰지 않고, 입장료·미니멈이 없는 비치바에서 칵테일만 시킵니다.

## 여는 방법

### 방법 1 — 그냥 열기
`index.html` 을 더블클릭. 브라우저에서 바로 열립니다.
단점: `file://` 로 열리면 브라우저가 외부 API 요청을 막아서 **우측 하단 채팅이 안 될 수 있습니다.**

### 방법 2 — 채팅까지 쓰려면 (권장)
`시작하기.command` 를 더블클릭.
로컬 서버(`http://localhost:8765`)를 띄우고 브라우저를 엽니다. 채팅이 정상 동작합니다.
터미널 창을 닫으면 서버가 꺼집니다.

> 처음 실행할 때 "개발자를 확인할 수 없다"고 나오면
> 파일을 **우클릭 → 열기** 로 한 번만 실행하면 이후에는 더블클릭으로 됩니다.

## 인쇄

`local/docs.html` 을 그대로 인쇄하면 e-티켓 2장과 객실 컨펌넘버가 한 장에 나옵니다.
안내문의 "항공티켓은 프린트해가시는 게 좋습니다" 항목이 이걸로 해결됩니다.

## 폰에서 보기

로컬 파일이라 맥에서만 열립니다. 발리에서 폰으로 보려면 셋 중 하나:
1. 이 폴더를 iCloud Drive / 드라이브에 올리고 폰 파일 앱에서 `index.html` 열기
2. 필요한 페이지만 PDF로 인쇄해서 폰에 저장 (오프라인에서 가장 확실)
3. 나중에 GitHub Pages 로 올리기 — `.gitignore` 가 `local/` 을 제외하므로
   컨펌넘버·e-티켓은 공개되지 않습니다. 대신 08 문서 링크는 깨집니다.

## 오프라인

폰트만 CDN에서 불러옵니다. 비행기 모드에서는 시스템 폰트로 대체되어 열립니다.
내용·이미지·체크리스트는 전부 폴더 안에 있어 인터넷 없이 동작합니다.
단, 채팅은 인터넷이 필요합니다.

## 채팅

우측 하단 버튼. 본인 Anthropic API 키를 입력창에 넣으면 일정과 투어 브리핑 전문을
컨텍스트로 질문할 수 있습니다. 키는 해당 브라우저 localStorage 에만 저장됩니다.
공용 PC에서는 저장하지 마세요.

## 수정

- `assets/data.js` — 타임라인(`DAYS`), 예약 보드(`TASKS`), 출국 전 체크리스트(`PRE`), 채팅 컨텍스트(`systemPrompt`)
- `assets/style.css` — 전 페이지 공용 스타일
- `assets/app.js` — 공용 동작. 해당 요소가 없는 페이지에서는 자동으로 건너뜁니다
